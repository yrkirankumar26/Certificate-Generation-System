# Certificate Generation System (CertifyPro) A premium Flask-based system to generate branded PDF certificates in bulk, with QR verification, email delivery, and a stunning glassmorphism dashboard. ## Features - Bulk certificate generation from CSV/XLSX - Custom certificate templates (PNG/JPG) with a beautiful built-in fallback - QR code on every certificate linking to a verification page - Admin authentication (hashed passwords, session-based) - Dashboard with Chart.js analytics (by month, course, template, daily) - History with search, sort, delete, and CSV export - Email delivery via SMTP - Settings module persisted in SQLite - Responsive glassmorphism UI (dark + light), animated background, toasts ## Folder Structure ``` Certificate-Generation-System/ app.py, generator.py, database.py, config.py, qr_generator.py, email_sender.py requirements.txt, README.md templates/ (Jinja HTML) static/ (css, js, images) uploads/, certificates/, templates_certificates/, generated_zip/ database/history.db reports/, screenshots/ ``` ## Technology Stack - Backend: Python 3.12+, Flask, SQLite, Pandas, OpenPyXL, ReportLab, Pillow, qrcode, python-dotenv - Frontend: HTML5, CSS3, Bootstrap 5, JavaScript (ES6), Chart.js, Font Awesome, AOS ## Installation (VS Code) ### Create Virtual Environment Windows: ```bash python -m venv venv venv\Scripts\activate ``` Linux/macOS: ```bash python3 -m venv venv source venv/bin/activate ``` ### Install Dependencies ```bash pip install -r requirements.txt ``` ### Run ```bash python app.py ``` Open: `http://127.0.0.1:5000` ## Default Admin - Username: `admin` - Password: `admin123` ## Environment Variables (optional `.env`) ``` SECRET_KEY=change-me APP_URL=http://127.0.0.1:5000 SMTP_HOST=smtp.gmail.com SMTP_PORT=587 SMTP_USER=your@email.com SMTP_PASS=app-password SMTP_FROM=your@email.com ``` ## Usage 1. Login as admin. 2. Upload a CSV/XLSX with participant data (see expected columns on the Upload page). 3. Optionally upload a certificate background template (PNG/JPG). 4. Generate → preview → download individual PDFs or the full ZIP. 5. Share certificates; participants can verify via `/verify` using ID or QR. ## Screenshots Place your screenshots in `screenshots/` and reference here. ## Future Enhancements - Multi-tenant orgs, role-based access - Drag-and-drop template designer - WhatsApp delivery integration - Blockchain-anchored verification ## License MIT
